# XR Tour Editor

Визуальный редактор виртуальных 360°/3D/XR-туров на базе Three.js и WebXR.

## Что умеет

- добавлять equirectangular-панорамы JPG / PNG / WEBP;
- добавлять сцены **«Объект 360°»** из `.object360.zip`, экспортированного Android-приложением Object360Capture;
- загружать **STL 3D-модели** (binary / ASCII STL) как отдельный тип сцены;
- создавать смешанные туры из панорам, вращаемых Object360 и STL-моделей;
- добавлять поверх любой сцены текстовые объекты **«Заголовок»** и **«Описание»**, перетаскивать их мышью и настраивать оформление;
- добавлять фоновую музыку всего тура, отдельную музыку сцены и дикторскую озвучку;
- ставить hotspot непосредственно на **Object360** и на поверхность **STL 3D**;
- строить **схему связей сцен** с поиском сцен без входящих переходов;
- управлять **слоями**: видимость, блокировка и порядок;
- использовать **Undo / Redo** через кнопки и Ctrl+Z / Ctrl+Y;
- создавать **экскурсию с гидом**: маршрут, длительность шага, автоозвучка и подсветка hotspot;
- добавлять медиа-слои: **фото, галерея, видео, аудио, PDF и кнопки**;
- выбирать эффекты перехода: Fade, Zoom, Blur, Portal, Glitch, Cinematic Black;
- предзагружать сцены, на которые ведут переходы;
- анализировать размер проекта и автоматически оптимизировать изображения при ZIP-экспорте;
- показывать стартовый экран **«Начать со звуком / без звука»**;
- экспортировать тур как **PWA** с Service Worker и полным offline-кэшем;
- включать **kiosk-режим**, полноэкранный просмотр и мобильную нижнюю панель;
- генерировать QR-код публичной ссылки на экскурсию.
- создавать несколько сцен;
- создавать универсальные точки-переходы из панорамы в панораму, Object360 или STL 3D;
- выбирать картинки для переходов: стрелка, вперёд, дверь, лестница, авто-превью целевой сцены или загруженная PNG / WEBP / SVG;
- настраивать свечение каждой точки отдельно: цвет, радиус, интенсивность и пульсацию;
- создавать информационные точки и внешние ссылки;
- ставить точку двойным кликом непосредственно по панораме;
- сохранять стартовый ракурс сцены (pitch / yaw / hfov);
- выбирать стартовую сцену;
- настраивать fade между сценами и автоповорот;
- предварительно просматривать готовый тур;
- автоматически сохранять текущий проект в браузере;
- экспортировать проект в JSON вместе с изображениями;
- импортировать ранее экспортированный проект;
- экспортировать полностью готовый автономный ZIP-тур со страницей просмотра, JavaScript, CSS, локальным Pannellum, панорамами и кадрами Object360;
- генерировать мультирезолюшн-тайлы Pannellum прямо в браузере при экспорте ZIP, без Python / Hugin / nona.

## Запуск

Проект не требует npm или сборки. Нужен обычный HTTP-сервер.

### Windows — самый простой запуск

В репозитории уже есть встроенный локальный сервер, поэтому **Python, Node.js, PHP и установка дополнительных программ не нужны**.

1. Скачайте / клонируйте репозиторий на Windows.
2. Дважды щёлкните **`start-server.bat`**.
3. Автоматически откроется браузер с редактором:

```
http://127.0.0.1:8080/
```

Окно сервера нужно оставить открытым. Для остановки нажмите **Ctrl+C** или закройте окно.

Если порт 8080 занят, сервер сам попробует следующие порты до 8100 и покажет фактический адрес. Также порт можно задать вручную:

```bat
start-server.bat 9000
```

Сервер раздаёт файлы только с локального компьютера через `127.0.0.1`, поддерживает большие файлы и HTTP Range-запросы для панорам.

### Python

```bash
python -m http.server 8080
```

Откройте:

```
http://localhost:8080
```

### PHP

```bash
php -S localhost:8080
```

> Pannellum подключается через jsDelivr CDN. Для полностью офлайн-режима достаточно скачать `pannellum.js` и `pannellum.css` в проект и заменить ссылки в `index.html`.

## Формат панорамы

Лучше всего использовать equirectangular-изображения с соотношением сторон **2:1**, например:

- 4096×2048
- 6000×3000
- 8192×4096

## Как создать переход

1. Добавьте минимум две сцены любого типа.
2. Откройте панораму, из которой должен выполняться переход.
3. Поверните камеру в нужное место.
4. Сделайте двойной клик по месту перехода или нажмите **«+ Точка»**.
5. Выберите тип **«Переход»**.
6. В поле **«Перейти в сцену»** выберите цель:
   - `◌ Панорама 360°`;
   - `◉ Object360`;
   - `◆ STL 3D`.
7. Выберите иконку перехода и, при необходимости, авто-превью.
8. Сохраните точку.

В готовом туре переход автоматически открывает нужный viewer. Для Object360 и STL текущий Pannellum закрывается и запускается соответствующий просмотрщик. Кнопка **«← Назад»** использует историю навигации и возвращает посетителя в предыдущую сцену.

## Сцена «Объект 360°»

Редактор поддерживает отдельный тип сцены для предметной 360°-съёмки. Это не сферическая панорама: камера находится снаружи объекта и снимает его с последовательных ракурсов.

### Импорт из Android Object360Capture

1. В Android-приложении снимите объект в режиме 36 / 72 кадров и, при необходимости, 3 ряда.
2. Нажмите экспорт ZIP.
3. В редакторе нажмите **«+»** в блоке сцен.
4. Выберите **«Объект 360°»**.
5. Загрузите `.object360.zip`.

Поддерживается структура:

```text
config.json
row_1/
  frame_000.jpg
  frame_001.jpg
  ...
row_2/
  ...
row_3/
  ...
```

Редактор автоматически читает `sectors`, `rows`, режим съёмки и дополнительные ARCore-параметры из `config.json`. Если часть метаданных отсутствует, количество рядов и секторов определяется по именам кадров.

### Управление Object360

- drag влево / вправо — вращение объекта;
- drag вверх / вниз — переход между уровнями съёмки;
- колесо мыши — масштаб;
- стрелки клавиатуры — покадровое вращение и переключение рядов;
- пробел / кнопка ▶ — автопрокрутка;
- **«Сохранить текущий кадр»** — сохранить стартовый сектор и ряд сцены.

У объектной сцены можно заменить исходный ZIP без удаления самой сцены.

### Экспорт готового тура

При экспорте автономного ZIP кадры объектных сцен сохраняются отдельно:

```text
object360/
  scene-id/
    row_1/
      frame_000.jpg
      ...
```

В готовый тур автоматически добавляется `assets/object360.js`. В левом верхнем углу экспортированного тура есть меню сцен, позволяющее переключаться между Three.js-панорамами и сценами «Объект 360°».

Hotspot-переход из панорамы может вести в любую сцену: другую панораму, Object360 или STL 3D. В редакторе тип целевой сцены показывается прямо в списке выбора. В экспортированном туре после перехода на Object360/STL появляется кнопка возврата к предыдущей сцене.

## Сцена «STL 3D»

Редактор умеет загружать STL-файл как отдельную интерактивную сцену. Используется встроенный WebGL-просмотрщик без Three.js и других внешних библиотек, поэтому STL работает и в полностью автономном экспортированном туре.

Поддерживается:

- binary STL;
- ASCII STL;
- автоматическое центрирование модели;
- автоматический масштаб независимо от исходных единиц STL;
- вращение мышью и пальцем;
- zoom колесом мыши;
- управление стрелками;
- режимы **SOLID / WIREFRAME**;
- выбор цвета модели;
- автоматическое вращение;
- сохранение стартового yaw / pitch / zoom;
- замена STL-файла без удаления сцены.

### Фон STL-сцены

Для каждой STL-модели фон настраивается отдельно:

- **Hi-Tech** — тёмный цифровой фон с сеткой и мягким свечением;
- **Чёрный** — чистый чёрный;
- **Светлый** — светлый нейтральный градиент;
- **Градиент** — цветной cinematic-градиент;
- **Прозрачный** — прозрачный WebGL-фон;
- **Своя картинка** — JPG / PNG / WEBP;
- **Панорама 360° из проекта** — можно выбрать любую панорамную сцену проекта как окружение модели.

В режиме **«Панорама 360° из проекта»** equirectangular-фон синхронизируется с yaw STL-модели: при вращении модели фон смещается по горизонтали, создавая эффект окружающего пространства.

Фон сохраняется в JSON проекта, используется в редакторе, предпросмотре и готовом автономном туре. При ZIP-экспорте пользовательские картинки и панорамные фоны упаковываются в папку `backgrounds/`.

### Добавление STL

1. Нажмите **«+»** в списке сцен.
2. Выберите **«STL 3D»**.
3. Укажите название.
4. Загрузите файл `.stl`.
5. После загрузки редактор покажет число треугольников и исходные размеры модели.

При экспорте готового тура STL-файлы записываются в:

```text
models/
  model-name.stl
```

В автономный ZIP также добавляется `assets/stl-viewer.js`, поэтому Интернет для просмотра модели не нужен.

На STL-сцену можно перейти напрямую из hotspot обычной панорамы. Вернуться можно кнопкой «← Назад» или выбрать другую сцену в верхнем меню готового тура.

## Текстовые объекты

На любую сцену — панораму, Object360 или STL — можно добавить текст поверх изображения.

Поддерживаются два типа:

- **Заголовок** — крупный акцентный текст;
- **Описание** — обычный многострочный текст.

Для каждого объекта настраиваются позиция X/Y, ширина, размер шрифта, цвет, выравнивание, фон блока и анимация появления (**Fade / Slide / без анимации**). В редакторе текст можно перетаскивать мышью прямо поверх сцены; двойной клик открывает настройки.

Текстовые объекты сохраняются в JSON проекта и автоматически отображаются в предпросмотре и готовом автономном туре.

## Музыка и озвучка

В проекте есть три уровня аудио:

1. **Музыка тура** — общая фоновая дорожка, продолжающаяся между сценами.
2. **Музыка сцены** — если задана, временно заменяет общую музыку только в этой сцене.
3. **Озвучка / диктор** — отдельная дорожка сцены, запускаемая посетителем кнопкой 🔊.

Поддерживаются MP3, OGG и WAV, регулировка громкости и loop для музыки. В готовом туре справа внизу появляются компактные кнопки **♪** и **🔊**. Во время дикторской озвучки музыка автоматически приглушается.

Современные браузеры запрещают автоматический старт звука до первого действия пользователя. Поэтому музыка запускается после первого клика / касания / клавиши в туре.

Отдельно в разделе **«Медиа»** можно добавить **аудио-объект** MP3 / OGG / WAV прямо поверх сцены. Для него доступны громкость, автозапуск, повтор и три вида отображения: **компактный плеер**, **большой плеер** и **скрытый фон**. Аудио-объект сохраняется как слой, может быть перемещён по сцене и при ZIP-экспорте упаковывается в каталог `media/<scene>/`.


При экспорте все дорожки упаковываются в:

```text
audio/
  project-music.mp3
  scene-...-music.mp3
  scene-...-narration.mp3
```

## V6 — интерактивный конструктор

### Hotspot на Object360

В сцене Object360 кнопка **«+ Точка»** доступна так же, как в панораме. Ещё удобнее — сделать двойной клик по нужному месту объекта.

Hotspot запоминает:

- сектор / кадр Object360;
- ряд съёмки;
- позицию X/Y на экране.

При вращении объекта точка показывается только рядом с тем ракурсом, на котором она была установлена. Она может вести в любую сцену, открывать URL или показывать информацию.

### Hotspot на STL 3D

При двойном клике по STL выполняется raycast по треугольникам модели. В проект сохраняется настоящая 3D-точка на поверхности:

```text
modelPoint: [x, y, z]
```

При вращении, zoom и смене ракурса позиция hotspot пересчитывается через 3D-проекцию. Если двойной клик не попал в геометрию, используется запасная экранная привязка к текущему ракурсу.

### Схема связей

Кнопка **«Схема»** открывает node-view всех сцен и переходов. На схеме видно:

- тип каждой сцены;
- стартовую сцену;
- количество исходящих переходов;
- связи hotspot и кнопок;
- сцены без входящих переходов;
- битые ссылки.

Клик по узлу выбирает соответствующую сцену в редакторе.

### Слои

Текст, медиа и hotspot отображаются в общей панели **«Слои»**. Для каждого слоя доступны:

- 👁 показать / скрыть;
- 🔒 заблокировать от случайного перемещения;
- ↑ поднять;
- ↓ опустить.

### Undo / Redo

Редактор хранит до 60 последних состояний проекта:

- **Ctrl+Z** — отменить;
- **Ctrl+Y** или **Ctrl+Shift+Z** — повторить;
- кнопки ↶ / ↷ находятся в верхней панели.

### Экскурсия с гидом

Кнопка **«Гид»** открывает редактор маршрута. Каждый шаг содержит:

- сцену;
- длительность в секундах;
- автоматический запуск дикторской озвучки;
- hotspot, который нужно подсветить.

В готовом туре появляется **▶ Гид**. Посетитель может остановить маршрут и перейти в свободный просмотр.

### Медиа-объекты

Поверх Panorama, Object360 и STL можно размещать:

- фото;
- галерею;
- видео MP4 / WEBM;
- PDF;
- кнопку.

Объекты позиционируются в процентах X/Y, имеют ширину / высоту, режим Contain / Cover и анимацию появления. Кнопка может открывать URL или другую сцену.

### Переходы

Для hotspot-перехода можно выбрать:

- Fade;
- Zoom;
- Blur dissolve;
- Portal;
- Digital glitch;
- Cinematic black.

Обычный эффект проекта задаётся в настройках, но для каждой точки его можно переопределить.

### Предзагрузка

Готовый tour.js анализирует переходы текущей сцены и заранее подгружает наиболее вероятные следующие ресурсы:

- панораму;
- первые Object360-кадры;
- STL;
- изображения медиа;
- аудио.

### Стартовый экран

В **«Публикация»** настраивается стартовый экран:

- заголовок;
- подзаголовок;
- обложка;
- **«Начать со звуком»**;
- **«Без звука»**.

Стартовый экран одновременно решает браузерное ограничение autoplay: нажатие пользователя разрешает воспроизведение музыки.

### Оптимизация экспорта

Перед экспортом можно выполнить **«Анализ размера проекта»**. Отдельно показываются:

- панорамы;
- Object360;
- STL;
- аудио;
- медиа;
- фоновые изображения.

При включённой автооптимизации браузер локально уменьшает большие растровые изображения и пережимает их с выбранным JPEG/WebP качеством. STL и аудиодорожки анализируются по размеру, но не перекодируются с потерей качества.

### PWA / Offline

При включённом PWA в ZIP добавляются:

```text
manifest.webmanifest
sw.js
icons/app-icon.svg
```

Service Worker предварительно кэширует сцены, Object360, STL, аудио, медиа и multires-тайлы. После установки PWA тур можно открывать без подключения к Интернету.

### Kiosk и мобильный просмотр

Kiosk-режим скрывает меню сцен, блокирует контекстное меню, удерживает внутреннюю навигацию и при запуске пытается перейти в fullscreen.

В публичном viewer есть адаптивная нижняя панель:

```text
▶ Гид   ⛶   ♪   🔊
```

### QR

В окне **«Публикация»** можно указать публичный URL тура. Редактор генерирует QR-код и позволяет скачать PNG. При ZIP-экспорте QR также записывается в `qr-tour.png`.

## Multiresolution

В блоке **«Проект»** можно включить **«Multiresolution ZIP»**. В редакторе исходная equirectangular-панорама остаётся без изменений, а при экспорте ZIP браузер автоматически:

1. преобразует панораму в 6 кубических граней `f / b / u / d / l / r`;
2. создаёт несколько уровней детализации;
3. режет уровни на JPEG-тайлы;
4. создаёт fallback-грани;
5. записывает для сцены конфигурацию Pannellum `type: "multires"`.

Настройки:

- **Размер тайла** — 512 или 1024 px. 512 даёт более мелкую подгрузку, 1024 уменьшает число файлов;
- **JPEG качество** — 50–100%;
- **Макс. грань куба** — 2048 / 4096 / 8192 px. По умолчанию 4096 для разумного баланса качества, времени упаковки и размера ZIP.

Тайлы попадают в:

```
multires/
  scene-id/
    1/
    2/
    3/
    ...
    fallback/
```

Генерация выполняется локально через WebGL и может занять заметное время для большого количества сцен. Дополнительные программы на Windows не требуются.

## Экспорт

**Экспорт проекта** сохраняет редакторский JSON с панорамами, Object360-кадрами и STL-моделями в виде встроенных данных. Такой файл можно потом снова импортировать в редактор.

**Экспорт тура ZIP** создаёт готовый автономный архив. Внутри находится отдельная папка тура со страницей `index.html`, `assets/tour.js`, `assets/tour.css`, `tour.json`, папкой `images/` с панорамами обычного экспорта, `object360/` с кадрами Object360, `models/` с STL-моделями, `backgrounds/` с фонами STL-сцен, `audio/` с музыкой и озвучкой, `media/` с фото/видео/PDF, `multires/` с тайлами при включённом Multiresolution, `images/icons/` с картинками и авто-превью переходов, локальной копией Pannellum в `vendor/pannellum/`, а также `start-server.bat` и `server.ps1`. На Windows после распаковки достаточно дважды щёлкнуть `start-server.bat` — локальный сервер запустится и тур откроется в браузере. Для просмотра Интернет не требуется.

## Интеграция с Laravel

Экспортированную конфигурацию можно использовать как основу для JSON-поля тура в БД. Сами панорамы рекомендуется хранить в `storage/app/public/panoramas`, а в конфиг подставлять URL из `Storage::url(...)`.

Pannellum распространяется отдельно на условиях своей лицензии.


## XR Media / Cardboard

Редактор поддерживает отдельный тип сцены **XR 180/360** на Three.js/WebXR.

- Источник: MP4, WEBM, JPG, PNG или WEBP.
- Проекции: 360 mono, 180 mono, 360/180 stereo LR и 360/180 stereo Top-Bottom.
- Обычный режим: мышь / touch, изменение FOV.
- На телефоне: Cardboard с разделением экрана и DeviceOrientation.
- В WebXR-совместимом браузере: кнопка XR и immersive-vr.
- В экспортируемый ZIP кладутся XR-медиа, XR viewer и локальная Three.js, поэтому обычный просмотр работает офлайн; immersive WebXR на опубликованном сайте требует HTTPS (localhost допускается браузерами как безопасный контекст).

Медиа-объекты также поддерживают **Стерео фото**. Можно добавить SBS/LR или Top-Bottom изображение поверх любой сцены; у объекта есть обычный просмотр, Cardboard и XR.


## Единый Three.js / WebXR движок

Pannellum больше не используется как движок просмотра. Все основные типы сцен работают через Three.js/WebXR:

- Панорама 360° — Three.js equirectangular sphere, Cardboard и WebXR.
- XR 180/360 — mono, LR/SBS и Top-Bottom, Cardboard и WebXR.
- STL — настоящая Three.js 3D-модель с wireframe/solid, Cardboard и WebXR.
- Object360 — последовательность кадров на виртуальном Three.js-экране, Cardboard и WebXR.
- Стерео-фото — LR/SBS или Top-Bottom через Three.js.
- Текстовые объекты, медиа-объекты, кнопки и hotspot’ы передаются в immersive WebXR через DOM Overlay, когда браузер/шлем поддерживает эту возможность.

Экспортируемый ZIP содержит локальные Three.js-файлы и XR-viewer'ы. Pannellum в новый ZIP не включается.

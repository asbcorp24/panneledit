# Object 360 Capture — Android MVP

Android-приложение для последовательной съёмки объекта со всех сторон.

## Что уже работает

### Обычный режим

- CameraX preview + JPEG capture.
- 36 или 72 сектора на полный оборот.
- Кольцо покрытия поверх камеры:
  - серый — ещё не снят;
  - зелёный — снят;
  - жёлтый — текущий сектор.
- Калибровка начального направления кнопкой `СТАРТ / 0°`.
- Один ряд или три ряда (низ / середина / верх).
- Ручная съёмка.
- AUTO: кадр снимается, когда телефон стабилен и попал близко к центру нового сектора.
- Экран обзора с миниатюрами и пропущенными секторами.
- Экспорт проекта в `.object360.zip` + `config.json`.

### ARCore-режим

- Отдельная кнопка **ARCORE — ТОЧНАЯ СЪЁМКА ПО ТРАЕКТОРИИ**.
- ARCore 1.56.0 работает как AR Optional: обычный режим остаётся доступным и на телефонах без ARCore.
- Центр объекта фиксируется через AR Anchor.
- Приложение считает реальную позицию камеры относительно центра объекта по XYZ, а не только направление телефона.
- Показываются:
  - текущий угол вокруг объекта;
  - текущий и эталонный радиус;
  - ошибка по высоте;
  - сектор 36/72;
  - снятые и пропущенные сектора.
- Подсказки в реальном времени:
  - подойти ближе / отойти дальше;
  - поднять / опустить телефон;
  - навести прицел точнее;
  - сместиться до центра следующего сектора.
- AUTO делает снимок только когда радиус, высота, направление, сектор и неподвижность телефона находятся в допуске.
- Для 3 рядов рассчитывается отдельная целевая высота для нижнего / среднего / верхнего круга.
- ARCore используется и как источник кадра: приложение выбирает максимально доступное CPU-разрешение камеры и сохраняет JPEG.
- AR-экспорт создаёт `.ar.object360.zip` и записывает в `config.json` радиус, расстояние между рядами и выбранную глубину объекта.

## Как пользоваться

1. Поставьте объект в центре свободного пространства с равномерным светом.
2. Встаньте в начальной точке и держите объект строго в центральном прицеле.
3. Выберите 36 (10°) или 72 (5°) кадра.
4. Нажмите `СТАРТ / 0°`.
5. Медленно обходите объект, всё время удерживая его центр в прицеле.
6. Делайте снимки вручную или включите `AUTO`.
7. В режиме `3 РЯДА` снимите средний круг, затем верхний и нижний.
8. Нажмите `ОБЗОР`: серые ячейки — пропущенные ракурсы.
9. `ZIP` создаёт архив кадров и метаданных.

## Как пользоваться ARCore-режимом

1. Нажмите **ARCORE — ТОЧНАЯ СЪЁМКА ПО ТРАЕКТОРИИ**.
2. Медленно поводите телефоном по объекту и окружению, пока ARCore не начнёт стабильно отслеживать положение.
3. Выберите 36 или 72 сектора.
4. Выберите 1 или 3 ряда.
5. Кнопкой **ГЛУБИНА** задайте примерную глубину объекта:
   - 20 см — небольшой предмет;
   - 50 см — крупный предмет;
   - 100/200 см — оборудование, мебель, большие экспонаты;
   - 0 — использовать найденную переднюю поверхность без поправки.
6. Держите прицел на видимом центре объекта и нажмите **ЗАДАТЬ ЦЕНТР**.
7. Приложение берёт точку поверхности и сдвигает виртуальный центр внутрь объекта на половину выбранной глубины.
8. Обходите объект. Следуйте подсказкам по радиусу, высоте и наведению.
9. Можно снимать кнопкой или включить **AUTO**.
10. В **ОБЗОРЕ** отображаются номера всех пропущенных секторов.
11. **ZIP** сохраняет снимки и геометрию съёмки.

### Почему нужна настройка глубины

ARCore hit-test обычно попадает в видимую переднюю поверхность. Но для круговой траектории нужен приблизительный геометрический центр объекта. Поэтому приложение позволяет указать примерную глубину и переносит Anchor внутрь предмета на половину этой величины. Для крупного объекта это заметно улучшает расчёт угла и постоянного радиуса.

## Ограничения

- Обычный режим по-прежнему использует датчики ориентации и остаётся резервным вариантом.
- ARCore-режим требует ARCore-совместимый Android 7.0+ и Google Play Services for AR.
- Точность зависит от освещения и количества визуальных деталей в сцене. На однотонных/блестящих поверхностях полезно, чтобы в кадре было видно окружение.
- Разрешение AR-снимка зависит от максимальной CPU camera configuration, поддерживаемой ARCore на конкретном телефоне.

## Сборка

Требования:

- Android Studio с JDK 17.
- Android SDK API 37.
- AGP 9.4.0 / Gradle 9.6.0.

Откройте папку проекта в Android Studio, дождитесь Gradle Sync и запустите на физическом телефоне.

### Windows: сборка APK одним BAT-файлом

Запустите двойным кликом:

`BUILD-APK-WINDOWS.bat`

Скрипт сам:

- ищет Java / JDK, включая встроенный JBR Android Studio;
- ищет Android SDK и при необходимости создаёт `local.properties`;
- использует установленный Gradle, а если его нет — скачивает Gradle 9.6.0;
- выполняет `clean assembleDebug`;
- копирует готовый APK в `APK/Object360Capture-debug.apk`;
- открывает Проводник Windows с выделенным готовым APK.

Для первого запуска нужен интернет, если Gradle ещё не установлен/не скачан. Готовый debug APK можно сразу устанавливать на Android.
